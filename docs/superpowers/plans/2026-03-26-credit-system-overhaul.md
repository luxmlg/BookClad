> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Overhaul the credit/pricing system — swap Quick model, introduce credit pools with expiry, add Studio tier, priority queue, and reposition Quick as prototyping-only.

**Architecture:** New `CreditPool` model tracks credit buckets with source, priority, and expiry. All credit operations (reserve, refund, grant) create/modify pools while maintaining a denormalized `User.creditBalance` for fast reads. Quick mode becomes draft-only (no upscale, no KDP export). BullMQ priority gives Pro/Studio users faster queue processing.

**Tech Stack:** Next.js 16, Prisma 7 (Postgres), BullMQ, DodoPayments, Sharp, react-konva

**Spec:** `docs/superpowers/specs/2026-03-26-credit-system-overhaul-design.md`

- [ ] **Step 1: Add spendCredits function**

Add this new function. It acquires a row-level lock on the User to serialize concurrent spends, then drains pools in priority order (SUBSCRIPTION first, then FIFO by createdAt).

```typescript
import type { Prisma, PrismaClient } from "@/generated/prisma/client";

type TransactionClient = Parameters<Parameters<PrismaClient["$transaction"]>[0]>[0];

async function spendCredits(
  tx: TransactionClient,
  userId: string,
  amount: number,
): Promise<void> {
  // Lock the user row to serialize concurrent spends for this user
  await tx.$queryRaw`SELECT id FROM "User" WHERE id = ${userId} FOR UPDATE`;

  const pools = await tx.creditPool.findMany({
    where: {
      userId,
      remaining: { gt: 0 },
      OR: [{ expiresAt: null }, { expiresAt: { gt: new Date() } }],
    },
    orderBy: [
      { priority: "asc" },
      { createdAt: "asc" },
    ],
  });

  let remaining = amount;

  for (const pool of pools) {
    if (remaining <= 0) break;
    const take = Math.min(pool.remaining, remaining);
    await tx.creditPool.update({
      where: { id: pool.id },
      data: { remaining: { decrement: take } },
    });
    remaining -= take;
  }

  if (remaining > 0) {
    const available = amount - remaining;
    throw new InsufficientCreditsError(amount, available);
  }

  await tx.user.update({
    where: { id: userId },
    data: { creditBalance: { decrement: amount } },
  });
}
```

- [ ] **Step 2: Update webhook — handleSubscriptionRenewed**

In `src/app/api/webhooks/dodo/route.ts`, replace the existing `handleSubscriptionRenewed` function (lines 151-188). The renewal now zeroes out old subscription pools and creates a new one — **all in a single transaction** to prevent races or data loss:

```typescript
async function handleSubscriptionRenewed(
  event: UnwrapWebhookEvent & { type: "subscription.renewed" },
  webhookId: string,
): Promise<void> {
  if (!isSubscriptionEvent(event)) return;

  const { customer, product_id, next_billing_date } = event.data;
  const tier = tierFromProductId(product_id);
  if (!tier) return;

  const user = await findUserByDodoCustomer(customer.customer_id);
  if (!user) return;

  // Skip credit grant if this renewal was triggered by a plan change
  const PLAN_CHANGE_WINDOW = 5 * 60 * 1000;
  const recentPlanChange = user.lastPlanChangeAt &&
    Date.now() - new Date(user.lastPlanChangeAt).getTime() < PLAN_CHANGE_WINDOW;

  const tierCredits = TIER_CREDITS[tier] ?? 0;
  const currentPeriodEnd = new Date(next_billing_date);

  await prisma.$transaction(async (tx) => {
    await tx.user.update({
      where: { id: user.id },
      data: {
        subscriptionStatus: SUBSCRIPTION_STATUS.ACTIVE,
        currentPeriodEnd,
      },
    });

    if (!recentPlanChange) {
      // Zero out old subscription pools (no rollover)
      const oldPools = await tx.creditPool.findMany({
        where: { userId: user.id, source: "SUBSCRIPTION", remaining: { gt: 0 } },
      });
      const oldRemaining = oldPools.reduce((sum, p) => sum + p.remaining, 0);

      if (oldRemaining > 0) {
        await tx.creditPool.updateMany({
          where: { userId: user.id, source: "SUBSCRIPTION", remaining: { gt: 0 } },
          data: { remaining: 0 },
        });
      }

      // Create new subscription pool
      await tx.creditPool.create({
        data: {
          userId: user.id,
          source: "SUBSCRIPTION",
          originalAmount: tierCredits,
          remaining: tierCredits,
          priority: 0,
          expiresAt: currentPeriodEnd,
        },
      });

      // Update balance: remove old, add new
      const balanceDelta = tierCredits - oldRemaining;
      const updatedUser = await tx.user.update({
        where: { id: user.id },
        data: { creditBalance: { increment: balanceDelta } },
      });

      await tx.creditTransaction.create({
        data: {
          userId: user.id,
          amount: tierCredits,
          balanceAfter: updatedUser.creditBalance,
          type: "GRANT",
          description: `Subscription renewed: ${tier} plan`,
        },
      });
    }

    await tx.webhookEvent.update({
      where: { id: webhookId },
      data: { processed: true },
    });
  });
}
```

import { prisma } from "./prisma.js";

export async function sweepExpiredCredits(): Promise<number> {
  const expiredPools = await prisma.creditPool.findMany({
    where: {
      expiresAt: { lt: new Date() },
      remaining: { gt: 0 },
    },
    select: { id: true, userId: true, remaining: true },
  });

  let count = 0;

  for (const pool of expiredPools) {
    await prisma.$transaction(async (tx) => {
      await tx.creditPool.update({
        where: { id: pool.id },
        data: { remaining: 0 },
      });

      const user = await tx.user.update({
        where: { id: pool.userId },
        data: { creditBalance: { decrement: pool.remaining } },
      });

      await tx.creditTransaction.create({
        data: {
          userId: pool.userId,
          amount: -pool.remaining,
          balanceAfter: user.creditBalance,
          type: "EXPIRE",
          description: "Credits expired",
        },
      });
    });
    count++;
  }

  if (count > 0) {
    console.log(`[credit-expiry] Expired ${count} credit pools`);
  }

  return count;
}

const ONE_HOUR = 60 * 60 * 1000;

export function startCreditExpirySweep(): void {
  // Run on startup
  sweepExpiredCredits().catch((err) =>
    console.error("[credit-expiry] Startup sweep failed:", err)
  );

  // Run hourly
  setInterval(() => {
    sweepExpiredCredits().catch((err) =>
      console.error("[credit-expiry] Periodic sweep failed:", err)
    );
  }, ONE_HOUR);
}
